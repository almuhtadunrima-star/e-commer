# e-commer

# Nike.com Clone (React + Vite + Tailwind CSS)

Klon website resmi Nike (https://www.nike.com/) dengan tampilan modern, interaktif, dan responsif.

## ✨ Fitur-Fitur Utama

1. **Top Bar & Brand Switcher**:
   - Logo Jordan (Jumpman) & Converse
   - Find a Store, Help menu, Join Us & Sign In

2. **Main Navbar**:
   - Logo Nike Swoosh resmi
   - Kategori: New & Featured, Men, Women, Kids, Jordan, Sale
   - Live Search bar dengan kata kunci populer
   - Tombol Favorites/Wishlist dengan badge jumlah
   - Tombol Bag/Keranjang Belanja dengan badge jumlah
   - Mobile Navigation Drawer responsif

3. **Promo Announcement Carousel**:
   - Banner promo bergerak otomatis (Free shipping, diskon 40%, dll.)

4. **Hero Campaign Banner**:
   - Kampanye hero bergaya Nike ("FULLY INVESTED", "TRAIN EVERYTHING", "CROWN THE SEASON")
   - Visual resmi, label atlet, dan tombol CTA langsung

5. **Trending & Featured Carousel**:
   - Galeri scroll horizontal untuk rilis sepatu dan koleksi terbaru

6. **The Wall (Product Grid & Catalog)**:
   - Produk sepatu & pakaian dengan gambar resolusi tinggi langsung dari static.nike.com
   - Filter Kategori & Olahraga (Lifestyle, Running, Basketball, Training, Jordan)
   - Filter Gender & Rentang Harga
   - Fitur Pengurutan (Featured, Price: Low to High, Price: High to Low, Highest Rated)
   - Badge produk ("Best Seller", "Just In", "Sale")
   - Swatch pemilih warna interaktif langsung pada kartu produk

7. **Modal Detail Produk (Product Detail View)**:
   - Galeri gambar utama dan thumbnail
   - Pemilihan ukuran sepatu (US 7 - US 13) dengan panduan ukuran
   - Pemilihan warna dinamis
   - Tombol Add to Bag dan Favorite
   - Accordion info Free Delivery & 60-Day Returns

8. **Shopping Bag Drawer (Slide-Over)**:
   - Pengaturan jumlah item (+ / -) dan tombol hapus
   - Indikator progres gratis ongkir ($50+ Free Delivery)
   - Kupon promo (contoh: gunakan kode `NIKE20` untuk diskon 20%)
   - Rincian Subtotal, Ongkir, Pajak, dan Total
   - Fitur simulasi checkout terintegrasi

9. **Nike Membership & Footer**:
   - Banner keanggotaan Nike gratis dengan benefit eksklusif
   - Footer lengkap 4 kolom resmi Nike dengan legalitas, pemilih lokasi, dan link sosial media

---

## 🚀 Cara Menjalankan

Masuk ke folder `web-ecommer`:

```bash
cd web-ecommer
npm run dev
```

Buka browser di:
`http://localhost:3000/`
